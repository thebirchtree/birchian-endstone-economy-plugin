# birchian-endstone-economy-plugin
Birch's Claude ai Universal Economy Plugin
Featured commands are as follows
/balance [player], /money [player], /mymoney	Show a balance	everyone
/pay <player> <amount>	Send money	everyone
/baltop [page]	Richest players	everyone
/sell <item> [amount|all]	Sell from inventory (defaults to all of that item)	everyone
/sellhand [amount]	Sell the stack in your hand, or part of it	everyone
/sellall	Sell every sellable item in your inventory	everyone
/worth [item]	Check a price (uses your held item if none given)	everyone
/addmoney, /subtractmoney, /setmoney <player> <amount>	Admin money control	op
/transfermoney <from> <to> <amount>	Move money between two accounts	op
/ecoreload	Reload prices.json and config.json	op
/shop Opens the ShopGUI.
